---
title: Using Orderium
---

This page explains how you can use Orderium as a player on your server to get familiar with the system before you start configuring it as a server administrator.

This guide expects you to use the default configuration.

## Creating an order

To create an order, you first need to have money. Be sure you have some in your balance :).

1. Once you have money, execute `/orders` to open the main GUI of the plugin. In this GUI, you can see all the orders that are available for you to deliver.

2. However, we want to create an order. To do so, click the "Your Orders" button at the bottom.
You can see your orders in this GUI. You will see a button to create an order. Click it to open the order creation GUI.

3. Another GUI will open where you can select the item you want to order. You can use the arrow buttons to navigate through the pages of items.
You can also search for an item by clicking the "Search" button.
When you find the item you want, click it to select it.

4. Now a dialog will show up where you can select the amount of items you want to order and the price you want to pay for each item someone delivers.
When you are done filling in the inputs, click the "Confirm" button to create the order.

## Delivering items

Now that orders are created, you can start delivering items to orders of other players.

1. Open the main GUI by executing `/orders`. In here, you can choose an order to deliver, you can of course search for the one you want to deliver, just like choosing an item.

2. Simply click on the order you want to deliver. An empty container GUI should open, you can then put your items in the GUI to deliver them.
Once you've done so, escape the GUI. A confirmation dialog should show up before you actually deliver the items.

3. Clicking the confirm button in the dialog will deliver all the items you've put into the GUI, you will then earn money from those delivered items.

The dialog shows the amount of money you **might** get from delivering items. In reality, in some cases, only some of your items are delivered.
This happens because someone else can deliver items to the order while you are staying inside the dialog.

## Collecting items

After players deliver items to your order, you can collect these items.

1. Execute `/orders` to open the main GUI.
2. Enter the "Your Orders" GUI.
3. Select the order you want to collect items from.
4. A dialog will pop up with 2 buttons. Click on the "Collect Items" button.
5. After that, another dialog will show up and let you input a number as the amount of items you want to collect. Type in the desired amount and click Confirm.

## Canceling an order

Canceling an order takes the order off the list and refunds you money for the remaining items that have not been completed.

1. Execute `/orders` to open the main GUI.
2. Enter the "Your Orders" GUI.
3. Select the order you want to cancel.
4. A dialog will pop up with 2 buttons. Click on the "Cancel Order" button.
5. Click Confirm.
