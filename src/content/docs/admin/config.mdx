### Order placeholders

Order placeholders are placeholders provided by an order. Order placeholders include:
- `money-per`: Price per item of the order
- `paid`: The total money other players have earned from this order
- `total`: The amount of money the order owner spent to create this order
- `delivered`: The number of items other players delivered to this order
- `amount`: The number of items the owner requested to order
- `in-storage`: The number of items the owner can collect from this order
- `player`: The name of the order owner
- `order-status`: The status of the order
- `item`: The display name of this order
